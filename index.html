Architecture & Privacy

How PDFKit protects your documents

PDFKit is built as a self-contained browser application powered by pdf-lib and PDF.js. Files are read directly from disk into temporary RAM, transformed locally, and exported via Blob URLs. Resetting a workspace releases memory immediately.
